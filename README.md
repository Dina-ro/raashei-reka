# רעשי רקע · דף נחיתה

## מה יש בתיקייה
- `index.html` – כל הטקסטים והמבנה של הדף
- `style.css` – צבעים, גופנים ועיצוב
- `script.js` – מספר הוואטסאפ, ההודעה המוכנה והכפתור הצף בטלפון
- `assets/about-photo.jpg` – התמונה שלך (להחלפה: שומרות קובץ חדש באותו שם בדיוק)

## איך מעלים ל-GitHub Pages
1. יוצרות ריפו חדש ב-GitHub (למשל `raashei-reka`), ציבורי.
2. Add file → Upload files → גוררות את כל התוכן של התיקייה (כולל התיקייה assets).
3. Commit changes.
4. Settings → Pages → תחת Branch בוחרות `main` ו-`/ (root)` → Save.
5. אחרי דקה-שתיים הדף יעלה בכתובת: `https://USERNAME.github.io/raashei-reka/`
6. **חשוב לתצוגה בוואטסאפ:** ב-`index.html`, בשורה של `og:image`, מחליפות את `USERNAME` בשם המשתמש שלך בגיטהאב (ואם קראת לריפו בשם אחר, גם את `raashei-reka`). בלי זה, כששולחים את הקישור בוואטסאפ לא תופיע התמונה.
